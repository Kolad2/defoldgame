# BoneHierarchy

Компонент редактора для Defold 1.14.1. По кнопке **Create** создаёт обычные
редактируемые GO-кости **под GO, к которому прикреплён компонент**.
Корневые кости становятся непосредственными детьми этого GO, остальные
сохраняют вложенность скелета. Промежуточный объект или отдельная коллекция
не создаются.

## Использование

1. Перезагрузите проект после установки расширения.
2. Добавьте **BoneHierarchy** через **Add Component** к нужному GO.
3. В **Source** выберите `.glb`, содержащий кости модели.
4. Откройте `.collection`, содержащую этот GO, и выберите его компонент
   BoneHierarchy в Outline. Это работает и для встроенного GO, и для GO,
   подключённого ссылкой на `.go`.
5. Нажмите **Create**, затем сохраните коллекцию.

Сам файл `.go` хранит компоненты, но не дочерние GO. Поэтому Create нужно
нажимать в контексте экземпляра GO в коллекции. Для GO внутри подключённой
коллекции откройте исходную коллекцию.

**Id Prefix** необязателен: пустое значение использует имя GO-владельца,
например `character_hip`. Так разные экземпляры `.go` не конфликтуют.
Для ссылочного GO настройте Source и Id Prefix в исходном `.go`; в коллекции
эти поля доступны только для чтения, а кнопка Create работает для выбранного
экземпляра. Одинаковые
имена внутри одного GLB получают уникальные суффиксы; запрещённые в ID
символы заменяются на `_`.

Повторный Create при наличии совпадающих ID ничего не перезаписывает.
Для пересоздания отмените предыдущую операцию или удалите созданные кости.
Создание всей иерархии отменяется одним **Undo**.

## Что переносится

- Все уникальные joints из всех `skins` GLB, включая несколько арматур.
- Имена, родительские связи, position, quaternion rotation и scale.
- Трансформации родителей арматуры и промежуточных узлов без костей.
- Position/Rotation самого компонента; трансформация GO-владельца
  наследуется обычным способом.

Создаются кости в исходной позе GLB. Это самостоятельные GO: автоматическая
привязка к анимации `.model` и `model.get_go()` не добавляется. Меши, материалы
и обычные узлы сцены, не являющиеся joints, не создаются как GO.
Если GLB не содержит `skins/joints`, Status сообщает об отсутствии скелета.
Матрицы с shear, не представимые трансформацией GO, отклоняются до создания.

Если у `.model` включён **Create GO Bones**, движок по-прежнему создаст также
свои кости во время игры. Отключите эту настройку, если нужны только GO,
созданные редактором.

## Устройство

- `editor/src/bone_hierarchy.clj` — тип компонента, GLB-парсер и Create.
- `editor/resources/templates/template.bonehierarchy` — шаблон компонента.
- `plugins/share/bone-hierarchy-editor.jar` — готовый Bob builder.
- `source/com/dynamo/bob/pipeline/BoneHierarchyBuilder.java` — его исходник.

В игре авторский компонент компилируется в пустой `.scriptc` без callbacks.
GLB и код генератора не становятся runtime-зависимостями компонента.
Сами созданные GO собираются обычным способом. Если на GO-владельце есть
другие script-компоненты, учитывайте лимит компонентов скриптов проекта.

Плагин использует внутренний Clojure API редактора, как соседний
NavMeshConstructor; после обновления Defold может потребоваться адаптация.
Готовый JAR включён: Python, внешний GLB-конвертер и JDK для работы не нужны.
