У абстрактного объекта Door
Есть составляющеие:
1. Сама модель двери. .model
2. Область проема .collision_object (group "interation", mask "?" )
Пример приказа: Кликаешь, персонаж получает приказ идти в проем.
3. Область самой двери .collision_object (group "interation", mask "?" )
Приказ: если закрыта открыть и идти в проем, если открыта, закрыть.

Проблема:
Если архетиктура
```
door.go
├── door_1.model
├── doorway_1.collision_object
└── door_1.collision_object
```

1. Абстрактный объект двери застревает в конретной модели двери .model, и конкретных мешах для .collision_object.
Соответственно это полностью конретная дверь. Тоесть эта структрура заморожена.
Потому что нельзя менять компненты внутри run. 
2. Трудно при нажатии отделить два объекта при нажатии
doorway_1.collision_object
door_1.collision_object
так как при hit получается только .id связанного с компнентом .go.
